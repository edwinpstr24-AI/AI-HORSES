# AI Horses - Public Record

Every card is committed to this repository **before first post** and is 
never edited afterward. The git commit timestamp is the proof. 
Results are graded the following morning against the official Equibase 
chart, which is treated as ground truth over any other source.

The headline number is **winner-in-top-3**, not a win rate. Selections 
are built for coverage in multi-race exotics - the objective is that the 
winner appears somewhere in the three. Order inside the three carries no 
meaning and is not graded.

No-play races are excluded from the rate entirely. Declining to play is a 
decision, not an absence, and it is recorded as one.
